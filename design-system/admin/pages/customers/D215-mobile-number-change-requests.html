What it is

Mobile number changes asked for in the app (A19) that need Admin.

What you can do

  • See whether the new and the old number were verified by code.
  • Approve, reject with a reason, or call the person first.

What happens next

On approval the person signs in with the new number and the old number is released.

Edge cases and spec

  • The new number must be unused; otherwise approve is blocked with a link to the conflict (EC-A35, D207).
  • Old number lost: call the person on the new number before approving.
  • One change every 30 days (A19).
