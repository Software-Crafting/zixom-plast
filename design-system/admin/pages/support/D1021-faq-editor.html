What it is

Write or edit one FAQ answer. Opens with ?f=1 for an existing entry, or empty for a new one. From D1022 it starts with the search phrase.

What you can do

  • Write the question and answer, pick a topic, tags and machine series.
  • Save as draft or Publish.

What happens next

Back to Help and FAQ (D1020). Published answers show in the app at once.

Edge cases and spec

  • Leaving with changes asks first (D1808).
  • Hindi and special characters are stored as typed (EC-A08).
  • Two Admins edit: second save shows the diff (EC-A12).
