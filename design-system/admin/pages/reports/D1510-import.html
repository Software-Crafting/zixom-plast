    What it is

    Five step import wizard. Ready is step 1; each step is a demo state.

    What you can do

    • Choose a type and download its template.
    • Upload, pick the header row, map columns.
    • Review counts and row messages, choose duplicate handling, download the error file.
    • Import the valid rows.

    What happens next

    Import history (D1511), where an import can be undone within 24 hours.

    Edge cases and spec

    • Wrong file type or empty file is refused (EC-A29).
    • Row errors with numbers; import valid rows only (EC-A31).
    • Duplicates: Skip, Update or Create new (EC-A32).
    • Large files run in the background (EC-A33).
    • Dates read as DD/MM/YYYY; +91 and spaces cleaned; duplicate serials flagged.
