What it is

Every import with its counts and who ran it, Tally invoices included.

What you can do

  • Click a row for the details.
  • Download the file or the error file.
  • Undo an import within 24 hours.

What happens next

Fix the errors and import again (D1510).

Edge cases and spec

  • Undo removes only rows created by that import that nobody changed since.
  • Tally invoices: duplicate invoice numbers are skipped and counted.
  • After 24 hours Undo is gone.
  • A failed import saved nothing; the reason is shown.
