What it is

Edit an engineer's profile, region, skills, status and notes. Opens with ?e=sandeep or ?e=anita.

What you can do

  • Change any field except the employee code.
  • Set status Active or On leave.
  • Save.

What happens next

Back to Engineer detail (D702). The app shows the new region and skills (E703).

Edge cases and spec

  • Changing region or skills affects suggestions at once (Region changed state).
  • Mobile used by a customer is blocked (D207, EC-A35).
  • Another Admin saved: Stale state (EC-A12). Leaving with changes asks first (D1808).
