      What it is

      The text of the pre work safety checklist (E901), one template per machine type.

      What you can do

      • Pick a machine type, edit the draft: change, add, remove, reorder items.
      • Publish the draft as a new version.
      • Edit a published template to start a new draft.

      What happens next

      Engineers answer it before work (E901). Failures show in Safety reports (D736).

      Edge cases and spec

      • Each report stores the version used; old reports never change.
      • Published versions are read only. One draft per type.
      • Jobs started offline use the version on the phone.
