What it is

Master list of skills with the level scale used on engineer profiles.

What you can do

  • Add, rename or archive a skill.
  • See who has each skill and at what level.

What happens next

Skills are set per engineer in Edit engineer (D704) and drive suggestions in Assign engineer (D404).

Edge cases and spec

  • A skill in use cannot be deleted, only archived.
  • Duplicate names are refused.
  • The engineer sees skills read only in the app (E703).
