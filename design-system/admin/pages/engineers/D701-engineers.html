What it is

Every engineer with region, skills, duty from the app and today's jobs.

What you can do

  • Search, filter by region, skill and status, use saved views.
  • Click a row for the quick view; click the name for the full record.
  • Select rows to message, test push or export.

What happens next

Engineer detail (D702), Add engineer (D703), Duty board (D710), Engineer messages (D716).

Edge cases and spec

  • Device not seen for 7 days: amber chip (Device not seen state).
  • Duty (On duty, Busy, Off duty) comes from the app; On leave and Disabled are set here (section 11).
  • 25 rows by default (25, 50, 100).
