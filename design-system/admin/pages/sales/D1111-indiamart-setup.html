What it is

Connect IndiaMART, choose who gets the leads, and see if the webhook is healthy.

What you can do

  • Copy the address and key; rotate the key.
  • Send a test lead, set owner, rule, spam words and Pull key.
  • Pause intake.

What happens next

IndiaMART inbox (D1110), Log (D1112), Product mapping (D1113).

Edge cases and spec

  • States: Not set up, Waiting for first lead, Healthy, Degraded, Failing with reason, Paused.
  • Old key after rotation: requests rejected and shown in D1112 with a hint.
  • No lead for 48 hours: warning. Test leads are marked and can be deleted.
