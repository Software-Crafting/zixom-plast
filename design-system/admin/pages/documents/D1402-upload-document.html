    What it is

    Add a file to the library. Open with ?replace=afm760-manual to upload a new version.

    What you can do

    • Drop a file, set title, type, version, language.
    • Choose the models, a machine or a company it applies to.
    • Show it to customers or keep it for Admin.

    What happens next

    The file is scanned, then shows in the app. Opens in Document detail (D1403).

    Edge cases and spec

    • Scanning state before the file is live.
    • Too large or failed upload: per file error with Retry (EC-A29).
    • A new version keeps the old one (C1702).
