What it is

Release notes per app version, shown once in the app after an update (C1304).

What you can do

  • Add notes for a version, save a draft or publish.
  • Edit or unpublish published notes.

What happens next

The app shows the notes on first open after updating to that version.

Edge cases and spec

  • One set of notes per app version.
  • A draft for a version not yet in the store is not shown.
  • Section 13, D1303.
