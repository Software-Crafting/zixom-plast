What it is

Every machine Zixom has sold, one row each. Replaces the paper register.

What you can do

  • Search, filter, use saved views, choose columns.
  • Click a row for the quick view; click the serial for the machine.
  • Select rows to update the warranty end or export.
  • Add a machine or import from Excel.

What happens next

Machine detail (D302), Add machine (D303), Import (D1510), Bulk result (D1809).

Edge cases and spec

  • Machines added by customers are Pending and sit in Needs verification.
  • Warranty: In warranty, Expiring (60 days or fewer), Out of warranty.
  • Serials are unique and never reused.
  • Changing a warranty end keeps old claim decisions (EC-A38). Partial bulk failure (EC-A64).
