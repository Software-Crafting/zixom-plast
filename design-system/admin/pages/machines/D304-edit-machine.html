Machine register Edit

Edit machine

Needed when the serial, customer or warranty dates change. Kept in the machine history.
The customer sees changes in the app at once. Cancel

What it is

Edit one machine. Opens with ?m=ZP-TF-2310.

What you can do

  • Change any field from Add machine.
  • Give a reason when serial, customer or warranty dates change.
  • Save or cancel.

What happens next

Back to Machine detail (D302). Customer moves use Transfer (D306).

Edge cases and spec

  • Warranty dates changed with claims on the machine: warning, old decisions stay (EC-A38).
  • Another Admin saved first: stale banner with Reload or Compare (EC-A12).
  • Serial clash is blocked (EC-A36).
