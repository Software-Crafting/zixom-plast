What it is

Form for a new machine in the register. ?report=u4 fills it from an unlisted machine report.

What you can do

  • Pick the model; specifications fill from it.
  • Set dates; warranty end fills as start plus 12 months.
  • Save, save and add another, or save and create an AMC.

What happens next

Machine detail (D302), Create AMC contract (D603).

Edge cases and spec

  • Serial already used: blocked with the existing machine and Open (EC-A36).
  • Warranty end before start, model missing: inline errors.
  • Offline: form keeps its data, Save waits (EC-A01). Double click saves once (EC-A09).
