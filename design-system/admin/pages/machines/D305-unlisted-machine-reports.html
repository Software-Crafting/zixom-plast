What it is

Machines customers report from the app that are not in the register.

What you can do

  • Click a row to see the text and photos.
  • Create the machine (opens Add machine filled in), link to an existing one, ask for details or reject.

What happens next

Add machine (D303), Machine detail (D302).

Edge cases and spec

  • The customer is told the outcome in the app.
  • A typed serial close to an existing one is suggested for linking.
  • A serial already in the register cannot be created again (EC-A36).
