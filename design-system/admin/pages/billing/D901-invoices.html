What it is

GST invoices imported from Tally and proformas made here, with balance and status.

What you can do

  • Import from Tally (D1510); create a proforma for an advance (D902).
  • Search, filter by source, use saved views, choose columns.
  • Click a row for the quick view; click the number for the invoice.
  • Select rows to send reminders or download PDFs.
  • Billing menu opens credit notes, statements, reminders, settings.

What happens next

Invoice detail (D903), New proforma (D902), Offline verification (D912), Overdue follow up (D925).

Edge cases and spec

  • Overdue rows are red with days overdue.
  • The dashboard issues no GST invoice numbers; INV numbers are Tally vouchers.
  • Empty state explains the Tally import.
  • Invoices are never deleted; cancelled stays listed.
  • Bulk with some failures shows done and failed (EC-A64).
