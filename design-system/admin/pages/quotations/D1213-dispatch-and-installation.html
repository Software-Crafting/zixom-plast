Edit in Add machine

What it is

Dispatch, installation and the commissioning report of a machine order. Opens with ?o=ORD-2026-0214.

What you can do

  • Record dispatch and installation details.
  • Complete the commissioning checks; untick one to see Create disabled.
  • Create the machine record and invite the customer (Created).

What happens next

The machine appears in the register (D301) and in the customer's app; Edit in Add machine opens D303 prefilled.

Edge cases and spec

  • The installation date starts the 12 month warranty unless the order says otherwise.
  • Change the date to see the warranty move.
  • Flow F9 step 5. A serial already in the register is blocked (EC-A36).
