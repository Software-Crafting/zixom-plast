    Create machine records

    What it is

    One sales order or turnkey project from confirmation to commissioning. Opens with ?o=PRJ-2026-001; try ORD-2026-0213 or 0214.

    What you can do

    • Move to the next stage and tell the customer.
    • Record an advance, create the milestone invoice.
    • Open milestones, documents and the machines this order delivers.

    What happens next

    Project milestones (D1212), Dispatch and installation (D1213), Create invoice (D902), Add machine (D303).

    Edge cases and spec

    • Stage moves follow the order; no skipping (section 11).
    • Late orders show a red banner with the reason.
    • An order for a lead asks you to create the customer first.
