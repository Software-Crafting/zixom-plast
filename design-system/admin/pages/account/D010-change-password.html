What it is

Changes the signed in Admin's password.

What you can do

  • Enter the current password, then the new one twice.
  • Rules tick as you type.
  • Save signs out every other session.

What happens next

A Saved toast; other browsers return to Sign in (D001). Back to My profile (D009).

Edge cases and spec

  • Wrong current password (Wrong current).
  • Same as the old password is refused (Same old).
  • Rules: 10 or more characters, a letter, a number, not common (section 14).
