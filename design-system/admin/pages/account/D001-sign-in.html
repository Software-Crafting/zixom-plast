What it is

The first page when there is no session. Work email and password, then a code (D003).

What you can do

  • Continue checks the fields and opens Verify code. Enter submits.
  • Show or hide the password. Paste and password managers work.
  • Remember me skips the code on this browser for 30 days, not the password.

What happens next

Verify code (D003), then the dashboard (D101) or the page the Admin tried to open. Forgot password opens D002.

Edge cases and spec

  • Wrong details never say which field; tries left show after the third try.
  • 5 wrong tries lock for 15 minutes (EC-A54, D007).
  • Disabled account shows only after a correct password.
  • Offline disables Continue. Maintenance shows a banner (EC-A63).
  • Browser back after sign in does not show this page again.
