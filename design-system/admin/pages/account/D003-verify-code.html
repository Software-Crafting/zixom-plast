What it is

Second step of sign in: the 6 digit code sent to the work email.

What you can do

  • Type or paste the code; boxes move on by themselves.
  • Resend after 30 seconds, up to 3 times.
  • Verify opens the dashboard.

What happens next

Dashboard (D101), or the page the Admin tried to open. A first sign in shows the tour (D006).

Edge cases and spec

  • Code lasts 5 minutes (Expired).
  • 5 wrong tries lock for 15 minutes (Locked, D007).
  • 5 codes per hour per account (section 14).
  • A new browser or country adds a line in the code email.
