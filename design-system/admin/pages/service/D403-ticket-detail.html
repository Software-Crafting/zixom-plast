What it is

One service request from start to finish. Opens with ?t=TKT-2026-0126; any ticket number works.

What you can do

  • Only the actions allowed for the status show in the action bar (section 11).
  • Tabs: overview, timeline, report, estimate, parts, messages with internal notes, media, invoice, history.
  • Call the customer or engineer from the side cards.

What happens next

Assign (D404), Reschedule (D405), Cancel (D406), Hold (D407), Estimate (D408), Report review (D413), Close (D414), Invoice (D902).

Edge cases and spec

  • Live: changes from the app flash the block and show a toast (Live state).
  • Machine pending verification shows a banner; coverage unknown.
  • Engineer silent 30 minutes in travel: amber chip.
  • Another Admin saved: stale banner. Archived: read only.
  • An action from an old page is refused (EC-A14).
