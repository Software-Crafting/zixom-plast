What it is

Excel or CSV import for the catalogue, with a check before anything changes.

What you can do

  • Upload, map columns, check errors and matches, import.
  • For each match: Skip, Update or Create new.

What happens next

Parts appear in the catalogue (D801) and in the app when visible.

Edge cases and spec

  • Bad rows listed with row number and reason; import the valid rows only (EC-A31).
  • Rows matching existing parts: Skip, Update, Create new (EC-A32).
  • Over 10,000 rows runs in the background (EC-A33).
