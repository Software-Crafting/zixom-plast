What it is

One spare part order. Opens with ?o=ORD-2026-0209; 0205 to 0212 cover every status.

What you can do

  • Only the actions allowed for the status show (section 11).
  • Tabs: items, delivery, payment, timeline, messages.
  • Cancel before packing; refund if paid.

What happens next

Quote (D832), Pick and pack (D833), Shipment (D834), Returns (D835), Create invoice (D902), Refund (D922).

Edge cases and spec

  • Stock is reserved on approval and issued when packed.
  • Cancel is only allowed before packed; cancelling releases stock.
  • Payment failed keeps Pending payment.
  • Delivered orders can report a problem for 7 days.
