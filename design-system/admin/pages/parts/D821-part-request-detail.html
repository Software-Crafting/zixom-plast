What it is

One part request from an engineer. Opens with ?r=SPR-2026-0031; try 0030 (approved), 0028 (dispatched), 0029 (delivered), 0026 (rejected).

What you can do

  • Only the actions the status allows show.
  • Approve and reserve, approve partly, mark on order, reject with a reason.
  • Issue (D813), mark dispatched with courier, mark delivered.

What happens next

The engineer sees each change in the app (E502). Issue stock (D813), Ticket (D403), Hold (D407).

Edge cases and spec

  • Needed for this visit and not available: banner, ticket can go On hold.
  • Duplicate request links to the existing one (Duplicate state).
  • Part not in the catalogue: match or add (EC-A45, Unmatched state).
  • Warranty: price zero. Chargeable without a price: enter one; the customer approves.
  • Read only after delivered.
