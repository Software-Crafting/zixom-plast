What it is

Picker for the parts fitted on this visit, opened from report section 5. No prices.

What you can do

  • Search by name or number, or scan the barcode.
  • Set quantity 1 to 99, source, old part returned and its photo.
  • Mark a warranty part (defaults from coverage), remove a line.
  • Add a part not in the list by name for Stores to match.

What happens next

  • Done returns to E401 section 5 with the lines.
  • Stores matches manual parts later.

Edge cases and spec

  • Part does not fit this model: warning with Add anyway.
  • Duplicate line merges; quantity above what Stores issued warns.
  • Barcode not recognised: type the number. Offline: cached list.
  • Spec: section E4, E402
