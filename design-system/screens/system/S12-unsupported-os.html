Your phone software is too old

Zixom Connect cannot run on this version. Update your phone, then open the app again.

  1. Open Settings
  2. Tap General, then Software Update
  3. Install the update and open Zixom Connect
  1. Open Settings
  2. Tap System, then Software update
  3. Install the update and open Zixom Connect

If your phone has no update, the store page lists the phones the app supports.

Blocks the app at launch when the phone software is below what the app supports (EC-35). No version number is named here; the store page carries the current list. Rooted or jailbroken phones are a separate, non-blocking warning, S13.
