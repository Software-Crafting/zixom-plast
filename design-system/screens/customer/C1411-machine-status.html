Decommission

What it is

Bottom sheet from More on Machine detail to set the machine status.

What you can do

  • Pick Running, Idle, Under repair or Decommissioned.
  • Give a reason for Idle or Decommissioned.
  • Open the requests that block decommissioning.

What happens next

  • Save updates the status chip on C202 and the machines list.
  • Decommissioned asks to confirm, then service actions turn off.

Edge cases and spec

  • Open requests block Decommissioned.
  • Missing reason: inline error, Save off.
  • Offline: saved and sent when back online (EC-03).
  • Spec: section C14, C1411
