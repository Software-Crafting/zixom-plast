What it is

Pick several due invoices and pay them in one payment.

What you can do

  • Tick or untick invoices; overdue ones start ticked.
  • Select all or clear all. Types can be mixed.
  • See the running total, then Pay.

What happens next

  • Pay opens C803 with the selection, one Razorpay payment.

Edge cases and spec

  • An invoice changed while selected: list refreshes and a sheet says so (EC-22).
  • Nothing selected: Pay is disabled.
  • Offline: Pay disabled (EC-02).
  • Spec: section C16, C1607 · EC-22, EC-44
