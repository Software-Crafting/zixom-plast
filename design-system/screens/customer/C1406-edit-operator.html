What it is

Form to add or edit a machine operator.

What you can do

  • Enter name and 10 digit mobile.
  • Pick a shift: Morning, Evening, Night or General.
  • Add optional notes.

What happens next

  • Save returns to C1405.
  • Back with changes asks to discard.

Edge cases and spec

  • Invalid mobile: inline error.
  • Mobile already on this machine: error with a link to that operator (EC-41).
  • Edited by someone else: refresh banner (EC-22).
  • Spec: section C14, C1406 · EC-22, EC-41
